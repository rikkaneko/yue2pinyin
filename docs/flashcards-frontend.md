# Flashcards and frontend

`GET /word` returns a complete entry from `assests/words-hk/all-latest.yaml` as a JSON object. The app loads and validates the source once per worker at startup, then draws uniformly from entries with at least one `definitions[].eg[]` item whose Cantonese `yue` text is nonempty and not solely `X`. Entries without a usable Cantonese example are excluded. Repeated draws are possible.

The source path is configurable with `YEN2PINYIN_FLASHCARD_WORDS_PATH`. A missing or malformed file, or a file with no eligible records, prevents startup. The response preserves optional source fields rather than adding empty ones. The existing pronunciation routes are unchanged.

The standalone static page has two views and uses Bootstrap 5's default colors. On each load, the pronunciation input chooses one of six distinct example sentences as its placeholder. Analyze submits that sentence when the input is blank or whitespace only; typed input retains the 2,000-character limit. The pronunciation view sends text to `/approx_pinyin` and displays each word group with approximate Mandarin pinyin, Jyutpin, Cantonese text, and Play on aligned rows. Missing Jyutpin removes both reading lines and the word Play control. Adjacent unreadable letters and numbers are shown as one word; Latin words are kept whole even when the API supplies a fallback reading for individual letters. Spaces and punctuation remain separate. The groups stay on one line; the result box scrolls horizontally when needed, with an invisible scrollbar on mobile. Words with a pronunciation hint are underlined and show an info mark to their right. Clicking a marked word shows character-specific hints beside it; long pressing opens them in a dialog. Keyboard users can activate the hint button and press Shift+F10 for the dialog. The same renderer is used for the flashcard headword and Cantonese examples. The flashcard view fetches `/word`, shows headwords, annotations, review status, all definitions and examples, and obtains pronunciation for the primary headword and Cantonese examples from `/approx_pinyin`. In explanations and examples, `yue` and `eng` appear under `粵語` and `英語` headings. Raw example `jyutpin` and headword source readings are hidden in the UI because annotated pronunciation is shown separately; the API data is unchanged. Both requests use the single `apiBaseUrl` in `frontend/config.js`. Invalid configuration produces a visible error. Source text is inserted as text nodes to avoid interpreting dictionary content as HTML. Both views use browser `SpeechSynthesisUtterance` with `zh-HK`; a matching installed voice is selected when available.

Serve `frontend/` from a separate static server. For local use, run `python3 -m http.server 8080 --bind 127.0.0.1 --directory frontend` and open `http://localhost:8080/`; the default API base is `http://127.0.0.1:8000`. The HTML uses relative paths for local CSS and JavaScript. Bootstrap 5, jQuery 3, and Zod 4 load from versioned jsDelivr URLs and require browser internet access. FastAPI does not serve `/` or `/assets`. The Compose service still has no published host port by default.

Set `YEN2PINYIN_CORS_ORIGINS` to the static page's origin before starting the API. It accepts a comma-separated list of exact origins, wildcard subdomains such as `https://*.nekoid.cc` (excluding `https://nekoid.cc`), and numeric port wildcards such as `http://localhost:*`. CORS supports `GET`, `POST`, and `Content-Type` preflight without credentials. Invalid patterns fail at startup; an empty setting denies cross-origin browser requests.

Run `.venv/bin/python -m pytest -q` for API and conversion tests. For interactive regression, start both servers and run `BROWSER_TEST_URL=http://localhost:8080/ .venv/bin/python -m pytest -q tests/test_frontend_browser.py` with `agent-browser` installed. Set `BROWSER_TEST_API_URL` when the API is not on port 8000. The browser test covers example fallback, unreadable word grouping, Unicode alignment, input and API errors, hint cues and interactions, flashcard language labels, Cantonese speech settings, and mobile horizontal scrolling and navigation.
